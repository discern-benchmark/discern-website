Scientific agent benchmark

Can AI agents work like scientists?

DISCERN evaluates whether scientific AI agents can do more than complete a task. It tests whether they can judge data quality, verify analyses, and reason from evidence.

Scientific reasoning

Getting an answer is not the same as scientific discovery.

Traditional benchmarks often reward task completion. But scientific work also depends on recognizing flawed data, examining questionable analyses, and updating beliefs when evidence conflicts with prior expectations.

DISCERN asks whether an AI agent can make trustworthy scientific decisions at each of those stages, not only whether it produces a convincing answer.

Framework

Three levels of scientific evaluation.

From data quality to evidence-grounded hypothesis generation.

Level 1

Can the agent tell whether the data can be trusted?

Agents inspect scientific inputs and decide whether to accept, repair, or reject them in the presence of controlled defects and clean controls.

79 tasks

Focused on identifying data issues before the scientific reasoning pipeline goes any further.

Level 2

Can the agent tell whether the analysis is valid?

Agents evaluate outputs, assumptions, and methodological choices, then judge whether a conclusion should be trusted or revised.

102 tasks · 24 analysis families

Designed to test whether an agent can identify analytical failure modes and respond appropriately.

Level 3

Can the agent generate and revise scientific hypotheses from evidence?

Agents confront worlds where evidence may challenge familiar scientific priors, and must propose, defend, and revise hypotheses under critique.

22 scientific worlds

The hardest setting in the benchmark, focused on evidence-grounded discovery behavior rather than routine task execution.

The three levels are independently instantiated and scored.

Key findings

Scientific judgment remains the ultimate bottleneck.

DISCERN reveals that while AI agents can execute code, high-level hypothesis generation remains an unsolved frontier. Perfect-score rates drop sharply as the scientific reasoning demands increase.

Claude Fable 5 & Fable → Opus: selective refusal and fallback replay

Standalone Claude Fable 5 has incomplete coverage and is therefore excluded from ranking. Its reported scores are conditional on the tasks it answered; no overall score is reported.

The Fable → Opus fallback replay is constructed after evaluation by substituting the corresponding recorded Opus results for tasks Fable refused. This simulates a deployment in which refused tasks are passed to Opus. The replay also uses recorded Opus outputs for tasks not invoked under the refusal-stop protocol.
