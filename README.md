# DISCERN — clean website starter

A responsive, static public-facing website starter for the DISCERN scientific-agent benchmark.

## Files

- `index.html` — page structure and copy
- `styles.css` — clean visual styling and responsive layout
- `script.js` — L1/L2/L3 tabs and mobile menu
- `favicon.svg` — simple site icon

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Deploy as a static site on GitHub Pages, Netlify, Cloudflare Pages, or Vercel.

## Anonymity note
